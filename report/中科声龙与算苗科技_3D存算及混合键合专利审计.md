# 中科声龙与算苗科技：3D存算、DRAM与混合键合专利审计

**资料截点：2026-07-28｜检索对象：中科声龙科技发展（北京）有限公司、算苗科技（北京）有限公司｜证据等级：A4（专利公开文本）**

> **结论先行：** 中科声龙与算苗的专利组合呈现出明显的技术连续性：从PoW芯片、DRAM刷新、片上互连和存储—计算贴合，演进到AI矩阵计算、近端存储、DRAM控制、3D物理设计和计算—存储Hybrid Bonding。但两家公司是不同的专利申请主体，团队或业务“前身”报道不能替代专利权属文件。最关键的中科声龙混合键合专利 `CN219040074U` 已在2023年登记转让给 Shenglong (Singapore) Pte. Ltd.；算苗自己的 `CN121920305A`、`CN121925162A` 则首次以专利原文直接支撑其3D存算和Hybrid Bonding设计路线。上述专利均不能单独证明A4E已完成Cu–Cu量产、8层封装、160GB/16TB/s实测或客户出货。

### CN219040074U为何重要

该实用新型的公开文本不是泛泛提到“3D”：

1. 权利要求把存储电路芯片和数据处理电路芯片定义为相互贴合，并通过键合触点连接；
2. 说明书明确描述两个芯片各自的绝缘层、金属键合触点以及由此形成的Hybrid Bonding结构；
3. 将时序修正子电路从存储侧移到数据处理侧，以释放存储面积、缩短通信；
4. 写明存储电路可为DRAM，并含访问控制、位宽拆分、通道选择和自检；
5. 法律事件明确发生权利转让，因此它是团队/路线前史，不是算苗当前专利资产的当然组成。

它是“中科声龙在2022年已公开存储—计算混合键合设计”的强A4证据，也是理解算苗后续3D TokenPU叙事的重要前史；但A4专利披露仍不等于芯片制造、量产或出货。

## 4. 三项核心算苗专利的证据强度

### 4.1 CN121920305A：最直接的算苗Hybrid Bonding权利要求

- 申请号：`CN202610031451.4A`；申请/优先权日：2026-01-09；公开日：2026-04-24；截点状态显示Pending；
- 发明人：朱建豪、张雨生；申请人为算苗科技（北京）有限公司；
- 权利要求10：三维集成电路芯片包括算力芯片和存储芯片，二者通过混合键合结构实现互连；
- 说明书还披露TSV电源/地预留、32×16计算单元示例、存储控制区域、总线、层次化PnR与时序收敛。

因此，报告可以升级为：**算苗的计算—存储Hybrid Bonding不是只有官网营销文案，而有专利权利要求直接支撑。**但该权利要求并没有把Hybrid Bonding限定为Cu–Cu，也没有证明A4E采用、8层完成、性能实测、良率或出货。

### 4.2 CN121925162A：缓冲层解决3DIC连接点、布线和可测试性

- 申请号：`CN202610030757.8A`；申请/优先权日：2026-01-09；公开日：2026-04-24；截点状态显示Pending；
- 发明人：刘明、闫超、张雨生；申请人为算苗科技（北京）有限公司；
- 核心结构是在第一芯片层与第二芯片层间增加Buffer Die，用金属走线改变上下层连接点投影位置，缓解3DIC局部拥塞和Hard IP冲突；
- 说明书明确列出TSV和Hybrid Bonding两种垂直互连可能；计算层可含计算芯片，第二层可含一个或多个存储芯片，存储芯片之间也可用TSV或Hybrid Bonding；
- 缓冲层可加入选择、连接检测、串并/并串转换、缓存、端口冗余和功能检测。

这项专利更像3DIC设计和可制造/可测试性架构，而不是具体键合工艺recipe。它没有给Cu材料、oxide体系、pitch、CMP、W2W/D2W、温度、设备或良率。

### 4.3 CN121034366A：提高DRAM行访问效率，不是物理键合专利

- 申请号：`CN202511157290.5A`；申请/优先权日：2025-08-18；公开日：2025-11-28；发明人赵岩、尹磊祖；
- 访问请求携带下一次访问的行地址信息，使控制器在当前数据访问与预充电期间提前处理下一行激活；
- 技术作用是降低行切换等待、提高DRAM有效带宽利用率；
- 不涉及8层、160GB、16TB/s、Cu–Cu、W2W/D2W或产品出货。

## 5. 从中科声龙到算苗：什么可以说，什么不能说

### 可以说

1. 两组专利在发明人和技术主题上存在连续性：刘明、张雨生等名字跨越两组公开文本；
2. 中科声龙早期组合已覆盖PoW ASIC、DRAM刷新、缓存/路由、异构集成，以及存储—数据处理芯片Hybrid Bonding；
3. 算苗组合把方向推进到AI矩阵计算、大模型访存、NUMA/NoC、DRAM访问/刷新、3D物理设计、计算—存储Hybrid Bonding；
4. 这条演进逻辑与公司“内存墙—3D TokenPU”叙事在工程上相互吻合。

### 不能说

1. 不能把中科声龙名下或已转给新加坡声龙的专利计入算苗资产；
2. 不能因为发明人重合就推定算苗获得专利许可；
3. 不能把专利实施例当作A4E BOM、流片截面或制造方确认；
4. 不能用专利数量估算估值、收入、市场份额、晶圆产能或出货；
5. 不能把“Hybrid Bonding”自动具体化为Cu–Cu；只有权利要求/说明书明确金属触点时，才能说其结构与金属—介质混合键合一致，仍需材料和截面确认。
