**资料截点：2026-07-28｜重做版｜只使用公开网页与法定披露｜实际出货优先**

## 2. 物理一致性检查：这些数字意味着什么

以下是算术约束，不是新增事实：

- 若 160GB 是整颗可用容量且 8 层平均分配，则每层约 `20GB = 160Gb`。
- 若 16TB/s 在 8 个等价存储单元间平均分配，则每单元约 `2TB/s`。
- `16TB/s ÷ 160GB = 100 s⁻¹`，即峰值带宽足以每秒遍历约 100 次标称容量；这解释了它对 token 推理“内存墙”的潜在价值，但不能证明真实利用率。
- 160GB/8 的结果不能机械等同为“一层一颗 160Gb DRAM die”。“存储晶圆”可能包含多个 tile/die，可能在晶圆级堆叠后切割，也可能有非对称层、冗余和 ECC。

### 最自洽、但仍待证的封装解释

TSV、bump 与 Cu–Cu hybrid bonding 并不矛盾，它们可能位于不同界面：

1. 多层 memory wafer/tile 之间使用介质—介质加 Cu–Cu 直接键合，形成高密度短互连；
2. TSV 穿硅完成跨层垂直贯通、供电或信号引出；
3. bump 用于某些晶圆—逻辑、堆叠—封装基板或外部连接界面。

这是工程上可行的 A6 假设，不是 A4E 已公开的截面事实。要闭环必须取得 die/wafer 截面、bonding flow、W2W/D2W、pitch、互连层定义或供应链联合公告。

## 3. 为什么它高概率不是“现成 HBM”，但也不能断言非 HBM

HBM 是 JEDEC 高带宽 DRAM 产品、接口和 stack 体系；hybrid bonding 是互连工艺。算苗公开资料没有出现 HBM2E/HBM3/HBM3E/HBM4、JEDEC 接口、stack 数、base die、每 stack 容量或三大 HBM 原厂。

| 比较项 | 算苗公开架构线索 | 标准 HBM 路线 | 审计判断 |
|---|---|---|---|
| 集成对象 | 8 层“存储晶圆”直接叠在逻辑晶圆上 | 多颗独立 HBM stack 通过 interposer/RDL 与逻辑并列，stack 内 DRAM 垂直堆叠 | 算苗措辞更像 proprietary 3D memory-on-logic，但没有截面不能定案 |
| 容量 | 二级报道给 160GB | 容量由 stack 数、堆叠高度和 die 密度构成 | 数值本身既不能确认也不能排除 HBM |
| 带宽 | 公司宣称 16TB/s | 由 HBM 代际、stack 数和接口速率聚合 | 数值相容不等于接口相同 |
| 键合 | 官网称 hybrid bonding；用户线索为 Cu–Cu | 量产 HBM 长期以 TSV+TCB/micro-bump 为主，hybrid bonding 正在逐代评估/导入 | 两条路线部分相交，不是替代关系 |
| 商业供应链 | 未具名 | 三星、SK海力士、美光 + 逻辑/封装平台 | 不能把算苗计入任何 HBM 原厂订单 |

更值得优先验证的假设是：定制 DRAM memory wafer/tile + 超宽 I/O + 逻辑近接，通过 hybrid bonding/TSV 形成非标准 3D DRAM。该假设也解释了 CN121034366A 为什么更关注 DRAM 行访问调度，而不是仅依赖标准 HBM 接口堆带宽；但专利仍不能证明产品采用。

## 4. CN121034366A 到底证明什么

专利原文可定位信息为：题名“实现 DRAM 访问的方法及装置、DRAM 控制器”，公开号 CN121034366A，申请号 CN202511157290.5，申请人算苗科技（北京）有限公司，发明人赵岩、尹磊祖，申请日 2025-08-18、公开日 2025-11-28，截点状态为Pending。摘要写明：访问请求携带下一次访问行地址；控制器执行当前目标列访问和预充电时，利用下一次行地址进行下一次行激活。

其可能解决的是把当前访问与下一次 ACT 行激活重叠，减少行切换等待、提高有效带宽利用率。它是“控制器利用率”证据，不是“物理堆叠”证据：

- 能证明的上限：算苗申请主体在 DRAM 访问调度/控制器方向有公开研发披露；
- 不能证明：A4E 使用该专利、160GB、8 层、16TB/s、Cu–Cu、W2W/D2W、HBM、存储供应商、性能或出货；
- 专利即使写入实施例，也属于 A4 技术披露；产品采用仍需 datasheet、芯片/客户/制造方材料或实测交叉验证。

## 5. 中科声龙—算苗专利脉络：技术连续，不代表权属连续

专利检索显示，中科声龙与算苗的技术主题存在清晰演进：中科声龙早期覆盖PoW运算芯片、缓存/路由、DRAM刷新，并在 `CN219040074U` 中直接公开存储电路芯片与数据处理电路芯片的Hybrid Bonding；算苗随后形成AI矩阵计算、NoC/NUMA、DRAM访问/刷新/调度、3D物理设计与计算—存储Hybrid Bonding组合。

但必须同时保留法律边界：

- `中科声龙科技发展（北京）有限公司`与`算苗科技（北京）有限公司`是不同申请主体；媒体所称“前身”或团队延续不导致专利自动转移；
- `CN219040074U` 原申请人为中科声龙，Google Patents法律事件显示其于2023-07-10登记转让给 `Shenglong (Singapore) Pte. Ltd.`，不能计入算苗当前专利资产；
- 按申请人检索，Google Patents显示中科声龙约73条、算苗约27条结果；这些是检索结果，不是经去族后独立、有效、已授权专利数；
- 算苗约27条公开结果可分为AI计算、多核/NoC、存储访问/DRAM、测试和3D物理设计五组，其中直接命中Hybrid Bonding的关键项是 `CN121920305A` 与 `CN121925162A`。

### 兆易创新最重要的正确定位

兆易创新不是“因为做存储，所以大概率就是算苗供应商”。能落地的事实是：兆易具备利基 DRAM 产品定义/设计/品牌能力，长鑫为其提供部分代工；这使二者组合成为研究定制 memory wafer 时值得跟踪的国内链。可是公告产品仍是 DDR4/DDR3/LPDDR4 等利基型 DRAM，未出现 3D Cu–Cu、宽 I/O、HBM 或算苗。供应关系必须留空。

### 8 层 Cu–Cu 的真正硬瓶颈

1. **每层良率相乘。** 假设每一晶圆/界面的合格概率为 `y`，多层总成品率近似受到 `yⁿ` 约束；8 层任何颗粒、Cu recess、void、overlay 或 die 缺陷都会被放大。该式只说明方向，不能在无实测 `y` 时计算 A4E 良率。
2. **平坦度与洁净度。** Cu–Cu/介质直接键合不能像焊料凸点那样容忍较大形貌；CMP、清洗、颗粒与表面活化直接决定 void 和接触电阻。
3. **overlay 与晶圆形变。** 多次键合、薄化和热处理造成累计对准误差与 bow/warpage；“设备标称精度”不等于多层成品精度。
4. **热预算和应力。** 已完成器件晶圆不能承受任意高温；多层 Cu/介质/硅的应力累积影响界面、TSV 和后续可靠性。
5. **KGD/KGW 与不可返修。** W2W 吞吐高但坏区相乘；D2W 可挑选 good die 却更慢、更贵。8 层方案必须回答按 die 还是按 wafer 筛选、何时测试、如何冗余与失效隔离。
6. **供电与散热。** 16TB/s 会引入大规模 I/O 切换功耗；memory-on-logic 缩短互连，却可能把热源和热阻叠在一起。

## 8. 实际出货与 2025–2031 节奏：能填的只有状态，不能编销量

| 年份 | 算苗可审计状态 | A4E 实际单位出货 | 可以纳入实际数据的邻近链信息 |
|---:|---|---|---|
| 2025 | DRAM 控制器专利申请/公开线索；无 A4E 实物事件 | **公开未披露** | 兆易—长鑫利基 DRAM 相关采购代工实际发生额 11.82 亿元；这不是算苗采购 |
| 2026 | 6 月 15 日公司宣布流片；后续应进入晶圆制造、测试、封装验证 | **公开未披露** | 截至 3 月 30 日兆易—长鑫已发生 5.81 亿元；全年 57.11 亿元只是预计额度 |
| 2027 | 媒体转述公司目标为 A4E 年初量产交付、A4S 约 2 月流片 | **计划，不能填数** | 需等待 A4E 封装点亮、客户验证、销售确认 |
| 2028–2031 | 未见公司公开单位销量、产能或收入指引 | **不能填数** | 不以行业 CAGR、融资额、设备数或团队历史填补 |

“公开未披露”不等于物理出货为零；它意味着公开研究不能把该项目纳入实际销量汇总。用户若要求 2025–2031 销量规划，唯一严谨答案是：**公司没有公开可审计的单位规划，报告拒绝伪造。**可以建立触发式情景，但必须保持为 A6：

- Gate 1：晶圆完成与 wafer sort；
- Gate 2：8 层堆叠/封装完成、点亮、良率与可靠性；
- Gate 3：160GB/16TB/s 第三方或客户测试；
- Gate 4：具名客户小批验证；
- Gate 5：量产采购、实际交付单位和收入；
- Gate 6：第二来源/多客户和稳定季度交付。

在 Gate 5 前，不应给 2027–2031 任何“万颗/万片”数字。

## 9. 对算苗商业化的判断：真正的转折点

技术转折点不是“再宣布一次 hybrid bonding”，而是以下证据首次出现：

1. 产品资料把 160GB、16TB/s、存储介质、宽 I/O、ECC/冗余和功耗同时说明；
2. 封装截面明确 Cu–Cu 所在界面，以及 TSV、bump 在其他层级的角色；
3. 一家晶圆/存储/三维集成代工或封测伙伴具名确认；
4. 首颗封装点亮、持续带宽和热/可靠性结果；
5. 客户方而非算苗单方确认部署/验收；
6. 实际单位交付或产品收入出现。

如果只出现 tape-out、融资、专利、团队历史万片经验、匿名“头部客户”或扩产项目，均不能构成销量拐点。

## 10. 监工裁决

- **通过：** 算苗是 3D AI 芯片设计/方案方；公司宣布 A4E 流片；8 层、TSV+bump、16TB/s 可回溯到公司发布稿；Hybrid Bonding 可回溯到官网；160GB 可回溯到二级行业报道。
- **有条件通过：** Cu–Cu 作为用户提供且工程上与 hybrid bonding 一致的关键线索，但必须标“待算苗一手材料闭环”；CN121034366A 用于说明 DRAM 控制方向，不能映射产品采用。
- **不通过：** “A4E 已采用 HBM”“兆易/长鑫/武汉新芯是算苗供应商”“A4E 已量产或已有实际销量”“团队万片历史等于算苗当前出货”“2027–2031 有精确销量规划”。
- **当前最有价值的产业链观察：** 兆易—长鑫证明国内利基 DRAM 设计/代工商业链真实存在；新芯股份官网证明国内已有 TSV、hybrid bonding、多晶圆堆叠的三维集成代工平台。二者分别是“存储晶圆候选链”和“堆叠工艺候选链”，但尚未与算苗形成公开供应闭环。
