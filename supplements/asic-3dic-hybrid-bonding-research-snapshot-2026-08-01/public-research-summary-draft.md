**版本：** Draft v0.1

**状态：** 这是暂停时归档的执行摘要草案，**不是** 50 条 Debate 的最终 supervisor 签发件，也不是任何公司、产品、客户、供应链或商业表现的尽调结论。

## 结论先行

1. **技术前沿与商业出货必须分开写。** 公开一手资料证明先进 W2W Hybrid Bonding 已有细间距研究 test vehicle，并有制造商公开的 SoIC 平台量产状态；这些事实不能拼接成任意指定产品的实际 pitch、良率、有效 WPM、客户、销量或销售额。[P01][P03–P07]
2. **HB、TSV、2.5D 与 HBM 彼此有关，但不是同义词。** Direct Hybrid Bonding 是直接的介质/金属界面键合路线；TSV 是穿硅垂直互连；2.5D 通常依赖 RDL 或中介层；HBM 是高带宽存储产品与生态。任一对象可能同时涉及其中若干技术，但不能由“TSV”或“HBM”推定 direct Cu–Cu HB。[R-A][L-C0][P01][P06]
3. **公开密度和精度记录的正确用途是路线比较，而不是市场乘数。** 由 pitch 计算的 `sites/mm²` 只是 A6 名义几何换算；设备 alignment、研究 overlay、layout margin 与产品量产的 Cpk、良率或可售 I/O 是不同口径。[P02–P07][A6]
4. **供应链分析必须从公司名单升级为工序—证据—状态图谱。** 设计/EDA、晶圆、CMP/清洗、对准/键合、薄化、量测、测试、封装、热管理和系统认证是价值节点；公开相邻能力、设备宣传、工程文件或计划不能确认某特定产品的端到端供应关系。[R-C][R-D][R-E][L-C0][P02][P08][P09]
5. **2026–2031 的机会可讨论模块、触发条件和验证路径，不能在当前证据集下写成确定的真实年度产能、销量或销售额。** 当前 A1-Ø 表示尚未形成“明确 HB/TSV pitch 或 overlay + 产品 SKU + 客户/验收 + 期间交付或收入”的公开闭环，不表示技术、项目或市场为零。
6. **算苗/中科声龙相关专利只能作为技术主题线索。** 专利必须分别核验申请人/权利人、法律状态、转让/许可、同族与产品实施证据；不能按名称、发明人、历史项目或技术相似性自动合并专利池。[R-B][R-E]

## 二、路线边界：HB、TSV、micro-bump、2.5D 与 HBM

| 路线/对象 | 工程定义 | 可共用的需求 | 不可混同之处 |
|---|---|---|---|
| Direct Hybrid Bonding | 在平坦度、表面化学、洁净度和对准控制下形成直接键合的 3D 互连；可有 W2W、D2W/C2W 等模式。 | 设计协同、晶圆处理、量测、可靠性和测试。 | 不等同于所有 3D 封装，也不等同于仅有 TSV 或 micro-bump 的堆叠。 |
| TSV | 穿越硅体的垂直电互连。 | 服务于更短垂直连接、带宽/能效/面积目标。 | TSV 本身不说明顶层/底层采用 direct HB；TDV/nTSV 研究不等于通用 HBM TSV。 |
| micro-bump / TCB | 以微凸点和热压等实现 die 间连接。 | 可与 TSV、RDL、KGD、热管理和测试共存。 | 与 direct HB 的界面、工艺窗口、pitch、可靠性和成本结构不同。 |
| 2.5D / RDL / interposer | 通过重布线层或中介层实现多 die 横向互连与封装级集成。 | 都需要先进封装设计、基板/封装协同和测试。 | 不能因带宽高或有 RDL/TSV 就归类为 direct HB。 |
| HBM | 高带宽存储产品与生态。 | 高密度互连、带宽、热、KGD、良率和系统协同。 | HBM 不是键合方式；HBM 与 direct HB 必须分别统计。 |

### 为什么必须分开统计

把 HBM、TSV+bump/TCB、2.5D/RDL、3D NAND/CIS 和 direct HB 全部塞进同一个“3D IC / HB”分母，会同时造成技术、产能、商业和供应链错误。正确做法是先建立路线身份证：

`产品/测试对象 → 互连界面 → 堆叠方式 → 是否 TSV → 是否 RDL/interposer → 测试/可靠性状态 → 产品/客户/交付证据等级`

只有同一身份证下的记录才能在同一产能、销量或收入分母中相加。字段缺失时应留空。

## 四、供应链模块与六层产能

关键模块图：

`3D EDA/PDK/IP → logic/memory wafer → CMP/清洗/表面活化 → 对准/键合 → 临时键合/减薄/背面互连 → 量测/缺陷检测 → KGD/测试/可靠性 → 封装/基板/热 → 系统资格与客户验收`

模块名单不是供应商关系。对于任何具体产品，只有产品—工艺—客户—良率—产出/收入在同一证据链闭环时，才可以确认实际供应关系。

所有“产能”必须定位到下列六层：

`设计/铭牌能力 → 已安装能力 → 客户认证可用能力 → 良率后的有效能力 → 实际产出/出货 → 利用率`

设备订单、厂房、CapEx、平台营销、总 WPM、OSAT 合并营收、HBM/CoWoS 或其他先进封装产能均不可直接折算为 direct HB 的有效 WPM 或产品销量。

## 五、2026–2031：可讨论的机会与不可伪造的数字

### 可讨论的条件性机会

| 价值节点 | 商业需求 | 未来升级触发条件 |
|---|---|---|
| 3D EDA/PDK/接口验证 | 多 die 的层映射、DRC/LVS、时序、热/PDN、DFT/KGD 协同。 | 具名客户、tape-out、可审计服务/许可收入。 |
| CMP/清洗/表面活化 | 平坦度、Cu 表面、颗粒与界面质量。 | 具名产品资格、批次良率与可靠性证据。 |
| 对准/键合/量测 | 细 pitch、overlay、检查、缺陷控制。 | 产品级 post-bond 指标、有效产能与客户资格。 |
| 薄化/背面互连 | 多层 stack、翘曲控制、TSV/背面连接。 | 同一产品结构、可靠性与量产履历。 |
| KGD/测试/可靠性 | 多层 yield 乘法风险、repair、系统 bring-up。 | 测试覆盖、失效分布、质量/交付数据。 |
| 封装/热/系统认证 | 基板、供电、散热、系统集成与客户资格。 | 产品 SKU、客户验收、重复交付和收入。 |

### A6 模型的使用规则

若需要做 2026–2031 年度模型，只能以透明 A6 情景表示，并同时披露：路线、统计单位、产能六层位置、yield、utilization、ASP 假设、触发事件及反证条件。A6 必须和已发生的 A1 事实分表，不能被标为实际市场、实际出货或真实收入。

## 结语

当前可审计的结论是：3D IC / Hybrid Bonding 的技术前沿、供应链模块和工程瓶颈足以支撑系统性研究；但具体公司、产品、直接 HB 路线、供应关系、有效产能、价格、销量和销售额仍必须以同一对象的 A1 闭环为门槛。研究应以可证伪条件推进，而不是用最小 pitch、设备能力、专利或相邻产业能力填补商业数据空白。
