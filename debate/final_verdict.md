## 二、可直接吸收的结论

### 1. 赛道边界

1. **混合键合**应限定为介质—介质直接键合与 Cu–Cu 直接互连的高密度垂直互连工艺；必须与 TSV+bump/TCB、临时键合、普通晶圆键合、2.5D interposer/RDL/bridge 分开。
2. **HBM**是高带宽 DRAM 堆叠、接口、base die 和系统封装体系；它与混合键合共用 CMP、清洗、薄化、检测、测试、热、KGD、EDA 等多个环节，却不是同一件事。HBM4 的高 I/O 不等于所有厂商/所有界面已或将使用 Cu–Cu 混合键合。
3. **CIS、3D NAND、logic/cache、HBM、CPO/硅光、MEMS**应当分别看。它们的键合对象、工艺、商业单位、良率损失点、客户资格与扩产节奏不同，不能合成一个“3D IC/混合键合”统一出货市场。

### 2. 商业化的稳健例证（按证据层级写）

|赛道|可写的稳健结论|必须保留的限制|
|---|---|---|
|CIS|Sony 的公开技术材料可支持堆叠 CIS/direct Cu connection 的技术事实；堆叠 CIS 产品已长期商业化|不要将所有 Sony/全行业 stacked CIS、全部手机传感器或总 sensor 收入改写为 Cu–Cu direct-bond 出货|
|3D NAND|YMTC Xtacking、Kioxia CBA 等说明 array–periphery 分离制造/晶圆键合架构已商业化|每代产品是否为 Cu–Cu/oxide hybrid bond、pitch、良率、实际 die 数必须逐代原文确认；CuA/COPS/4D 等名称本身不是 Cu–Cu 证据|
|logic-on-cache|AMD 3D V-Cache 的 CPU/server SKU 是商业 3D cache/3D chiplet 的清晰产品例证，且与 TSMC SoIC 生态相关|单 SKU 的 SoIC/键合工艺 BOM、pitch、产能、良率、销售额和 die 数未公开，不可由 CPU 收入推算|
|2.5D/一般 3D 封装|Intel Foveros、CoWoS、EMIB、I-Cube/H-Cube 等已有商业产品/平台|Foveros 一般版本、CoWoS、HBM 2.5D 系统都不得自动升级为 Foveros Direct 或 Cu–Cu hybrid bond 出货|
|HBM|HBM 已有真实商业产品、收入和高端系统需求；HBM4 正处于各厂商产品/认证/量产准备的分化阶段|产品/收入/送样不能换算 direct-bond stack 数，也不能预设具体键合工艺|

### 3. 产业链与竞争要素

直接键合的竞争不是“是否有一台键合机”，而是以下链条能否作为一个可重复的产品流程闭环：

```text
设计/PDK/3D EDA
  → 合格逻辑/存储晶圆或 KGD
  → 沉积/电镀、CMP、清洗/活化、表面量测
  → W2W 或 D2W 对准与键合
  → 临时键合支撑下的薄化/背面/RDL
  → 键合后无损检测、KGD、burn-in、高速测试、失效分析
  → 基板/封装、TIM 与热/供电
  → 客户可靠性、系统 qualification、实际交付/收入
```

真正的竞争要素是平坦度、Cu recess、颗粒/金属污染、overlay、D2W KGD、薄化翘曲、void/界面检测、热/PDN、BER/测试覆盖、3D PDK/签核、材料与备件连续性、以及客户长期 qualification。设备、材料、OSAT、foundry、EDA 任一环节的单点能力都不足以证明端到端量产。

### 4. 中国大陆链

可吸收的中国结论是：大陆存在真实的存储制造、封测、CMP/减薄、清洗/电镀、刻蚀/沉积、量测/检测、测试、材料、基板、EDA 和下游设计模块生态。长江存储的 Xtacking 是商业化 3D NAND 制造例证；长鑫是 DRAM 制造主体；长电、通富、华天、盛合晶微等有真实先进封测/测试业务；拓荆、华海清科、盛美、北方华创、中微、中科飞测、精测、安集、鼎龙等在相应工序有产品或经营事实。

**但合并稿必须同时写出：** 截至资料截点，公开资料没有形成“一个中国大陆命名 AI/HBM/logic—memory 产品 + 明确 Cu–Cu/介质键合结构 + 指定 foundry/OSAT + 客户资格 + 良率/可靠性 + 有效产能 + 期间实际产出/交付”的可审计闭环。因此上述公司应被称作**工序模块参与者、能力候选或待验证承接方**，不是已被证明的端到端 Cu–Cu 混合键合规模量产供应链。

### 5. 算苗科技

可吸收的最终写法如下：

> SUNMMIO 官网可证明公司作出了 3D TokenPU、基于混合键合的 3D 堆叠、16 TB/s/160 GB 等产品/技术营销主张；媒体可旁证 A4E 流片及其宣称的“8 层存储晶圆 + TSV/bump”架构。上述证据分别是公司主张与媒体旁证，**不是** A4E 的第三方实测、Cu–Cu 工艺截面、HBM 认证、客户验收、有效产能或实际出货。公开资料未具名确认其存储、foundry、OSAT、键合设备、CMP/清洗/检测、材料、EDA 或客户；因此任何中国公司均不得被写为算苗已验证供应商。

兆易—长鑫关系可单列为**与算苗无关**的 DRAM 生态商业事实：2025 年实际发生额为 11.82 亿元；2026 年 57.11 亿元为预计关联交易额度，最终发布前必须回查上交所 PDF 表格/页码、交易对象和金额单位。

## 四、合并稿的推荐写法与禁用写法

|主题|推荐写法|禁止写法|
|---|---|---|
|全球市场|“公开资料可证明成熟应用、产品平台和设备商业活动，但未提供可同口径加总的 hybrid-bonded die/wafer/package 实物出货。”|“全球混合键合已经出货 X 亿颗”——除非给出统一来源、产品范围、期间和单位。|

|3D NAND|“Xtacking/CBA 证明 array–periphery 分离/键合商业架构。”|“3D NAND/ CuA/COPS/4D NAND 都是 Cu–Cu hybrid bonding。”|
|HBM|“HBM 与直接键合共享部分工艺链，具体键合取决于供应商和 SKU。”|“HBM4 必然/全面采用 hybrid bonding。”|
|平台|“SoIC/Foveros Direct/X-Cube 是公开平台或路线；特定客户产品需另证。”|“平台发布即代表客户量产和有效 WPM。”|

## 五、最终发布门槛

在总报告发布前，主控至少应确认以下修复已经完成：

- [ ] 删除或原始证据闭环 D 组 XMC/武汉新芯条目，并与 C 组统一；
- [ ] 对兆易—长鑫公告核对原 PDF 的标题、页码、交易对象、交易类别、2025 实际与 2026 预计；
- [ ] 对拓荆、华天等互动/媒体说法补原文件，补不到就统一降级；
- [ ] 对 Sony、AMD、YMTC/Kioxia 的“产品—工艺”关系采用分层句式，不用单一 “Cu–Cu量产”标签；
- [ ] 对算苗保留供应商、客户、良率、产能、出货的空白，不以技术/媒体/融资补全；
- [ ] 所有数值保留单位、期间、来源链接和证据等级；不做禁用换算；
- [ ] 对所有 2027—2031 描述标为情景、条件或监测项，而非销量承诺。

**完成上述修复后：** 五组素材可有条件地进入合并稿，主结论具有较强的可审计性；未完成时，尤其是 XMC 主体错配与中国供应关系问题，必须在发布版中剔除。
