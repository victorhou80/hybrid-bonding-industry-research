# 3D IC 2026—2031：30条独立监工交叉质询

**结构：** 6个主题 × A—E五组各1条，共30条；连续编号。
**裁决原则：** 原稿保持只读；“通过”表示命题可按限定语进入主报告，“有条件通过”表示必须完成所列修复，“驳回”表示不得进入主报告。

---

## 主题一：市场定义 / 销售额边界

### 质询01｜A组｜M1是否真能称“3D IC销售额”

- **被审命题：** 狭义3D IC制造/封装服务收入2026年约140亿美元，2031年365亿美元。
- **证据：** A组将stacked CIS、array—CMOS分离型NAND、HBM stack内部堆叠/测试、logic/cache/logic等纳入M1，并明确排除全部CoWoS、裸晶、HBM器件本体和设备材料；数值标A6。
- **质疑：** 公开财报并不按该口径拆分收入，模型也没有给出每应用“单位量×单位增量服务价值”的完整底表；因此它是可讨论的场景价值池，不是行业实际销售额。
- **严重度：** P1
- **修复要求：** 主表标题改为“狭义3D IC制造/封装服务收入（A6情景模型）”；单列M1定义、排除项、误差至少±25%和触发重估条件；不得在摘要删掉“A6”。
- **裁决：** **有条件通过。** 数字可作为基准情景，不可表述为已统计市场实际值。

### 质询02｜B组｜HBM attached价值量是否越过狭义边界

- **被审命题：** 2026—2028收入增长中心是“HBM + 大尺寸2.5D/3D系统封装”。
- **证据：** B组明确价值链含interposer/RDL/bridge、基板、组装、测试和热，并称其不等于Hybrid Bonding。
- **质疑：** 该口径横跨2.5D邻接市场与3D HBM stack，显著宽于A组M1；若把B组YoY套到A组M1，会把CoWoS/基板/热重复并入狭义销售额。
- **严重度：** P1
- **修复要求：** 在主报告把B组此项命名为“AI/HPC高密度系统集成邻接价值量”，不与M1相加；用桥接表区分HBM器件、stack内部3D服务、2.5D package、基板/热和整机。
- **裁决：** **有条件通过。** 趋势可用，不能直接驱动M1绝对额。

### 质询03｜C组｜五本产能账能否被加总成市场收入

- **被审命题：** 前道、2.5D、3D直接键合、HBM、OSAT/测试必须分别建账。
- **证据：** C组列出五种物理对象及禁止换算，指出晶圆当量、die尺寸、良率和计价单位不同。
- **质疑：** 主报告若为追求“一张总表”把这些账本相加，既重复计算同一产品又混合CapEx、产能与收入。
- **严重度：** P0
- **修复要求：** 禁止五本账横向相加；只允许用流程图说明依赖关系，并在每个数值旁注明物理单位和收入归属。
- **裁决：** **通过C组命题；驳回任何加总企图。** 这是发布门禁。

### 质询04｜D组｜“四个市场”是否仍被利润池表混合

- **被审命题：** 3D direct、2.5D先进封装、HBM器件和成熟CIS/NAND必须分赛道竞争。
- **证据：** D组开篇拆市场，并在利润池中区分foundry、OSAT、设备、材料、测试、终端产品溢价。
- **质疑：** 利润池表列出HBM、2.5D和3D共同受益环节，若没有收入归属字段，读者仍可能把“受益”理解为狭义3D/HB市场份额。
- **严重度：** P1
- **修复要求：** 每个利润池增加“核心M1/邻接M2或2.5D/终端M3”归属；“机会”与“收入已发生”分列。
- **裁决：** **有条件通过。** 框架正确，主报告需显式归属。

### 质询05｜E组｜中国能力地图能否称国产3D IC市场

- **被审命题：** 中国链覆盖设计、存储、制造、OSAT、设备、材料、测试、EDA和基板/热管理。
- **证据：** E组逐段列出公开能力，并明确“能力地图，不是供应商名单”。
- **质疑：** 企业具有相邻产品线并不等于获得Hybrid Bonding订单，更不能把公司总营收相加为国产3D IC销售额。
- **严重度：** P0
- **修复要求：** 主报告保持“能力存在/已验证产品/具名客户/实际收入”四级漏斗；无一手客户闭环的公司不得放入算苗供应链或HB收入表。
- **裁决：** **通过能力地图；驳回市场额和确认供应链外推。**

## 主题二：应用 / 渗透

### 质询06｜A组｜M1应用拆分是否可审计

- **被审命题：** 2031年M1中CIS 22%、NAND 20%、HBM内部服务22%、logic/cache 23%、CPO 7%。
- **证据：** A组给出2026—2031七类分项绝对额，并声明是A6分配而非厂商分部收入。
- **质疑：** 分项缺少可外部重建的采用率、量、ASP/服务价值假设；2027/2028/2030与主表分别有±0.01bn舍入差。
- **严重度：** P1
- **修复要求：** 附一张模型驱动表，至少列“商业状态、相对量增、单位服务强度、权重来源、误差”；合计统一到主表或加舍入脚注。
- **裁决：** **有条件通过。** 结构方向可用，精确占比须标A6和不确定性。

### 质询07｜B组｜“渗透率”不用百分比是否足够

- **被审命题：** 在缺统一分母时，采用“极低/低/中/高/很高”的分级比伪造2031统一渗透率更可审计。
- **证据：** B组逐应用给2026采用程度、2031基准状态及上修/下修触发器。
- **质疑：** 定性分级避免了假精确，却降低了跨年跟踪性；若没有明确定义，“中高”可能随作者主观漂移。
- **严重度：** P2
- **修复要求：** 为每一级补充可观测标准，例如具名SKU数、供应商数、连续季度交付、第二产品周期等；仍不得虚构百分比。
- **裁决：** **通过并要求增强。** 方法优于无分母百分比。

### 质询08｜C组｜应用需求能否直接决定供给紧张

- **被审命题：** 2026偏紧、2027紧平衡、2028结构分化、2030成熟产能可能过剩。
- **证据：** C组结合已公布扩产项目、2—6季度qualification与2—4年新厂周期，给出A6情景。
- **质疑：** 应用需求与package面积、HBM位数、测试时长之间没有数量桥；“偏紧/平衡”不能被误写成已观测利用率。
- **严重度：** P1
- **修复要求：** 表头明确“A6供需判断”；每年列至少一个可观测证伪指标（交期、利用率、客户qualification、基板/测试瓶颈），不填伪精确缺口WPM。
- **裁决：** **有条件通过。** 情景叙事可用，状态不是事实统计。

### 质询09｜D组｜logic-on-cache能否外推logic-on-logic

- **被审命题：** logic-on-cache向精选logic-on-logic/near-memory扩展，是2027—2029高价值增长曲线。
- **证据：** AMD 3D V-Cache提供商业锚；SoIC/Foveros Direct/X-Cube提供平台路线；D组设置第二/第三具名SKU和多客户复购触发器。
- **质疑：** cache die的功耗、良率容忍、die组合与高功耗logic-on-logic不同，商业成功不能自动迁移。
- **严重度：** P1
- **修复要求：** 两类应用分开建状态表；在出现具名logic-on-logic可售SKU和连续交付前，只列上行情景，不以V-Cache销量替代。
- **裁决：** **有条件通过。** “扩展”只能是待证路线，不是已兑现渗透。

### 质询10｜E组｜算苗能否成为应用渗透样本

- **被审命题：** 算苗A4E可能成为国产定制3D存算需求牵引者。
- **证据：** 公司/报道/专利呈现流片、3D存算、8层、160GB、16TB/s、Hybrid Bonding等不同层级线索；E组设置六级Gate。
- **质疑：** 截点无回片点亮、第三方实测、客户PoC、订单、单位交付或收入；它不能进入实际渗透率分子。
- **严重度：** P0
- **修复要求：** 仅放“观察案例/期权”；Gate 5前实际销量和销售额保持空白，Gate 3前160GB/16TB/s标公司/媒体主张而非实测。
- **裁决：** **驳回作为渗透样本；通过作为里程碑案例。**

## 主题三：产能 / 扩产 / 爬坡

### 质询11｜A组｜有效能力指数是否伪装成产能

- **被审命题：** 狭义3D/HB有效能力指数从2026=100增至2031基准265。
- **证据：** A组将安装验收、recipe、qualification和可重复良率纳入定义，并明确指数不是WPM。
- **质疑：** 指数权重和各应用产能折算未公开，读者可能把2.65倍直接换成wafer、die或销售额。
- **严重度：** P1
- **修复要求：** 标题加“A6综合指数”；禁止与任何厂商WPM并列在同一坐标轴；补充应用权重与重估规则，保留“不可线性换算收入/销量”。
- **裁决：** **有条件通过。** 只可表达方向和情景。

### 质询12｜B组｜资格周期区间是否被当成行业定律

- **被审命题：** HBM/XPU协同约12—24个月，direct 3D约18—36个月，车规24—48个月。
- **证据：** B组明确称工程经验A6区间，不是公司承诺，并按应用解释验证环节。
- **质疑：** 不同代际、复用平台、客户与可靠性规范差异大，区间不能用于反推出具体产品量产日。
- **严重度：** P2
- **修复要求：** 主报告保留区间和A6标签，添加“起点定义（样品/工艺冻结/客户送样）”；具体厂商只采用其官方状态。
- **裁决：** **通过并加限定。**

### 质询13｜C组｜扩产公告何时算有效产能

- **被审命题：** 只有M6稳定良率有效产能和M7实际出货/收入才可称可销售能力。
- **证据：** C组M0—M7框架区分选址、土建、工具、工艺验收、客户资格、良率和收入；项目金额均保留建设状态。
- **质疑：** “Intel Fab 9已经投产”“Micron 2026开始生产”等公司级状态仍不等于特定HB/3D产品的M6，更不提供统一WPM。
- **严重度：** P1
- **修复要求：** 每个扩产项目单列“公司原文状态”和“监工可确认成熟度”；M6/M7需产品级证据，无则停留M3—M5或写“混合状态”。
- **裁决：** **有条件通过。** 框架通过，个别项目不得整体升格。

### 质询14｜D组｜设备复购能否证明客户起量

- **被审命题：** 设备复购比首台更强，是产品闭环的重要领先指标。
- **证据：** D组七级漏斗要求可售SKU、稳定季度交付、多客户复制后才称起量。
- **质疑：** 复购可能服务研发、备份或另一工艺，仍不能证明具名终端产品收入；设备订单还可能取消或延期验收。
- **严重度：** P1
- **修复要求：** 复购只列领先指标；起量判定必须同时有客户产品映射、量产状态和连续交付/收入，至少两条独立证据闭环。
- **裁决：** **有条件通过。** 不得从复购单独推销量。

### 质询15｜E组｜大陆HB有效WPM为什么必须留空

- **被审命题：** 公开资料不足以汇总中国大陆Hybrid Bonding有效WPM。
- **证据：** E组指出工艺界面、产品对象、稳定良率、认证可售产能与客户交付五项通常无法同时取得。
- **质疑：** 市场报告常用厂房、工具UPH、项目CapEx或总WPM补洞；这种估算是否至少可作上限？
- **严重度：** P0
- **修复要求：** 不输出单点WPM；如必须建情景，只能给不具公司归属的A6指数/区间，并公开全部利用率、良率、产品组合假设，不能称实际产能。
- **裁决：** **通过留空原则；驳回伪精确上限。**

## 主题四：玩家roadmap / 客户 / 竞争

### 质询16｜A组｜收入模型是否暗含玩家份额

- **被审命题：** M1增长由CIS/NAND底盘、HBM复杂度、logic/cache和CPO推动。
- **证据：** A组引用TSMC、Sony、Intel、Samsung、存储IDM和设备商公开路线，但未给公司份额。
- **质疑：** 应用收入分配不能反推TSMC/Sony/AMD等玩家份额；同一产品可能同时贡献foundry、IDM与OSAT价值。
- **严重度：** P1
- **修复要求：** 主报告的市场模型与玩家表分离；没有公司拆分收入时，份额写“不可审计”，只做能力/生态定位。
- **裁决：** **通过市场驱动；驳回份额外推。**

### 质询17｜B组｜客户“起量”定义是否足够严格

- **被审命题：** 只有具名可售SKU、稳定交付和收入才能称起量，sample/qualification不算。
- **证据：** B组状态审计及风险表逐字区分送样、认证、量产准备与出货。
- **质疑：** “具名SKU”本身也可能销量极小；“volume production”可能是工艺平台而非终端产品。
- **严重度：** P1
- **修复要求：** 起量至少满足“可售产品+连续季度交付/收入或第二代复购”之一；平台volume production与客户product volume shipment分栏。
- **裁决：** **有条件通过。** 定义需从单点上市升级为持续商业闭环。

### 质询18｜C组｜TSMC/Intel/Samsung的扩产可否直接比较

- **被审命题：** 三家均拥有先进3D/封装平台，但外部客户、产品组合与披露尺度不同。
- **证据：** C组分别审计SoIC/CoWoS、Foveros/Foveros Direct/EMIB、X-Cube/I-Cube/HBM。
- **质疑：** 厂房投资、面积、集团CapEx、内部产品与外部foundry订单均不是同一量纲；直接做“产能排名”会误导。
- **严重度：** P0
- **修复要求：** 只比较平台状态、具名产品闭环、外部客户证据和区域供给；不以总CapEx/面积/WPM排统一榜。
- **裁决：** **通过分账；驳回统一产能排名。**

### 质询19｜D组｜1—5竞争评分有无可复现性

- **被审命题：** TSMC在先进节点/产品协同、HB学习、生态等维度相对领先；Intel/Samsung为挑战者，Sony是CIS标杆。
- **证据：** D组给六个维度评分并声明“定性，不是市场份额”。
- **质疑：** 未披露权重、打分阈值和逐格证据，数字外观会制造量化精确感；“透明度不足不影响能力”的表述也可能过度确定。
- **严重度：** P1
- **修复要求：** 主报告改为高/中/待证或补充评分规则与证据脚注；不得求综合分或映射份额；透明度不足应降低“可量化置信度”。
- **裁决：** **有条件通过。** 定位可用，数字评分不可裸用。

### 质询20｜E组｜能否推定算苗供应商和客户

- **被审命题：** 国产存储、foundry、OSAT、设备材料与算苗存在潜在协同机会。
- **证据：** E组列出大陆能力图和算苗产品/专利线索，但明确供应商字段留空。
- **质疑：** 地理相邻、技术相邻、兆易—长鑫真实采购或XMC平台能力均不能证明其为A4E供应方；“算苗前身是声龙”媒体说法也不能证明资产/客户连续性。
- **严重度：** P0
- **修复要求：** 未经双方公告、法定文件或可核验产品拆解，不得画实线供应关系；图中潜在线索只能用虚线并标“未确认”。
- **裁决：** **驳回所有未证实供应商/客户归因。**

## 主题五：中国机会及算苗 / 中科声龙

### 质询21｜A组｜算苗是否可计入M1/M3

- **被审命题：** 算苗/中科声龙相关3D存算是商业期权，需跨越流片—点亮—封装—客户认证—量产门槛。
- **证据：** A组明确截至截点无公开良率、供应商、单位出货，160GB/16TB/s不得进实际值。
- **质疑：** A组M1/M3基准是否在“其他/研发小量”中隐含计入算苗？原稿未给公司级权重，无法确认。
- **严重度：** P1
- **修复要求：** 主报告明确A4E在实际/公司收入栏为0/空白；A6总市场可以含匿名研发小量，但不得声称由算苗贡献，也不得单列销量。
- **裁决：** **有条件通过。** 算苗只能在机会监测章节出现。

### 质询22｜B组｜中国应用机会应跟全球渗透同斜率吗

- **被审命题：** AI/HPC、近存、CPO等全球增长会带动中国相关3D机会。
- **证据：** B组给全球应用YoY区间，并列出口管制、HBM可获得性、EDA与设备为风险。
- **质疑：** 中国在先进逻辑、HBM、EDA、设备维护和客户资格上的约束不同，不能直接套全球基准增速。
- **严重度：** P1
- **修复要求：** 中国章节只用全球区间作需求背景，另建“可获得供给/本地qualification/替代路线”折减与触发器；没有底表时不输出中国绝对销售额。
- **裁决：** **有条件通过。** 全球趋势不能机械本地化。

### 质询23｜C组｜中国扩产机会最先兑现在哪里

- **被审命题：** 跨路线共用的CMP、清洗、量测、薄化、测试、基板和热比单押HB键合机更稳健。
- **证据：** C组设备链说明这些环节同时服务HBM、2.5D、CIS/NAND与3D logic，且良率/认证形成复购。
- **质疑：** “共用”也意味着收入难以归属3D IC；国产替代、样机或客户验证不等于量产采购。
- **严重度：** P1
- **修复要求：** 机会排序使用“需求相关度×认证状态×复购证据×可归属收入”四维；公司总收入不得计入3D IC价值池。
- **裁决：** **有条件通过。** 商业机会成立，市场额归属仍待证。

### 质询24｜D组｜中科声龙技术前史能否强化算苗竞争力

- **被审命题：** 算苗与声龙存在沿革线索，其3D存算路线有相关专利前史。
- **证据：** 媒体报道“前身”线索；CN219040074U原申请人为中科声龙，后转让给Shenglong (Singapore) Pte. Ltd.；算苗另有CN121920305A/CN121925162A。
- **质疑：** 不同法人、专利权属和法律事件必须分开；技术主题相似不证明许可、团队、资产或产品采用连续。
- **严重度：** P0
- **修复要求：** 主报告只写“技术/人员沿革待法定文件确认”；CN219040074U列中科声龙/新加坡受让人，不计入算苗资产；算苗专利仅证明设计主张。
- **裁决：** **驳回资产连续性结论；保留技术前史线索。**

### 质询25｜E组｜A4E五个关键参数能否打包引用

- **被审命题：** A4E涉及8层、160GB、16TB/s、TSV+bump和Hybrid Bonding/Cu–Cu。
- **证据：** 公司声明、行业报道和专利分别支持不同字段；E组承认160GB/16TB/s无第三方实测，Cu–Cu仍待一手闭环。
- **质疑：** 将五项写在一个句子中会造成“同一正式规格、同一实物已实现”的错觉；TSV+bump与部分界面HB可以共存，但具体界面未知。
- **严重度：** P0
- **修复要求：** 建立逐字段证据矩阵：主张者、日期、证据等级、能证明/不能证明；禁止写“8层全部Cu–Cu”或“已实现160GB/16TB/s实测”。
- **裁决：** **仅逐字段有条件通过；打包命题驳回。**

## 主题六：来源 / 模型 / 可证伪性

### 质询26｜A组｜A6三层模型是否可复算

- **被审命题：** M1/M2/M3分别以21.1%/22.2%/17.4%基准CAGR增长，且三层不可相加。
- **证据：** 年度低/基准/高表、累计额、CAGR、应用拆分和误差区间齐备；监工复算正确。
- **质疑：** 算术可复算不等于模型可复建；基年锚、应用权重、单位价值与第三方校准过程尚不透明。
- **严重度：** P1
- **修复要求：** 发布模型附录，列每层的纳入/排除、基年构造、权重、关键公式、第三方校准和敏感性；明确A1/A2/A5只作锚，不是M1实际值。
- **裁决：** **算术通过，模型有条件通过。**

### 质询27｜B组｜来源无法重开时结论能否发布

- **被审命题：** B组基于既有已核验台账形成应用判断，本轮浏览器不可用不提升证据等级。
- **证据：** B组披露浏览限制，给出35项来源及A1—A6边界。
- **质疑：** 报告截止日为2026-07-29，HBM4、SoIC、CPO等状态高度时效；未重开网页可能遗漏更新或误引措辞。
- **严重度：** P1
- **修复要求：** 主控发布前重开关键官方原文，保存访问日期/标题/发布日期；无法访问的来源降级或删除依赖该来源的确定性表述。
- **裁决：** **底稿可用，发布暂缓至来源复核完成。**

### 质询28｜C组｜供给兑现公式是否可证伪

- **被审命题：** 有效供给=名义能力×安装兑现率×认证通过率×OEE×最终良率×产品组合系数。
- **证据：** 工程链条合理，能说明为何CapEx/工具WPH不能直接成为good package。
- **质疑：** 各系数不可观察且相互相关时，公式可能变成解释一切、无法证伪的框架。
- **严重度：** P1
- **修复要求：** 每个系数绑定可观察代理与更新频率；缺数据时只输出情景区间，不通过调参事后拟合；记录触发上/下修的阈值。
- **裁决：** **有条件通过。** 作为审计清单有效，作为数值预测需底表。

### 质询29｜D组｜竞争结论的证伪门槛是否对称

- **被审命题：** TSMC可能维持高端生态优势，Intel/Samsung/OSAT能否缩小差距取决于外部客户和复购。
- **证据：** D组为logic HB、HBM采用HB、OSAT、CPO、多来源分别列支持指标和证伪条件。
- **质疑：** 对领先者使用能力/生态证据，对挑战者要求收入/客户闭环，可能形成不对称门槛。
- **严重度：** P1
- **修复要求：** 所有玩家统一按平台能力、具名产品、外部客户、连续交付、第二代/复购五项评分；“未知”不得自动判领先或落后。
- **裁决：** **有条件通过。** 结论保留但需同尺比较。

### 质询30｜E组｜专利和媒体证据如何避免升级

- **被审命题：** 专利可证明技术主张/权利要求，媒体可提供事件线索，但均不证明量产、客户、良率或收入。
- **证据：** E组逐件区分CN219040074U、CN121920305A、CN121925162A，并标法定公告、官网、媒体和A6。
- **质疑：** 合稿压缩时最容易把A4/A5简化成“已掌握/已采用/已量产”，尤其算苗和国产设备材料。
- **严重度：** P0
- **修复要求：** 所有专利与媒体数字旁保留等级；实际栏只接受法定/公司实际披露或客户闭环；设置禁用词审查：无证据时不得写“采用、供应、量产、出货、收入”。
- **裁决：** **通过E组边界；该边界列为发布门禁。**
