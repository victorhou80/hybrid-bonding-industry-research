## 1. 审计口径与通过门槛

|等级|含义|主报告处理|
|---|---|---|
|**P0**|会把不同主体、不同工艺或不同状态错误并入事实账本；不修复会直接制造虚假供应关系/量产事实|删除、留空或降级；未修复不得进入总报告|
|**P1**|证据链不完整、来源级别与断言不匹配，或关键限定语不足|补入原件、精确日期/页码/原文，或改写为条件性表述|
|**P2**|口径、覆盖或可读性问题；不改变核心结论但会增加误读风险|增加脚注、限定语、监控项或交叉索引|

五份稿只有同时满足下列条件才可被总报告吸收：

1. 明确把 **Cu–Cu/介质混合键合** 与 TSV+bump/TCB、Foveros 一般版本、2.5D/RDL/CoWoS、3D NAND array–periphery 键合区分；
2. 明确把 **产品平台、样机/客户验证、建设/名义产能、有效产能、实际产出/收入** 区分；
3. 对 CIS、NAND、logic/cache、HBM、CPO/MEMS 分赛道，不把其中一条的商业化速度迁移给另一条；
4. 对中国链只称“工序相关能力/候选”直至出现型号—客户—工艺—资格—产出闭环；
5. 数字有原始来源、日期、口径和单位，且不得由收入、WPM、CapEx、设备订单或厂房面积反推 hybrid-bonded die/wafer/stack；
6. 供应关系必须由双方、客户或法定文件中的至少一方具名确认；技术适配、产品目录、专利和媒体转述都不能补全供应链。

## 3. 跨组已经通过的关键结论

以下内容在五稿中得到一致且审慎的处理，可进入总报告（仍保留来源标注）：

1. **HBM 是产品/接口/封装体系，hybrid bonding 是工艺；两者既不等同也不互相替代。** HBM4 的高 I/O、base die、热和测试压力提高了更高密度互连的动机，但不证明所有 HBM4 已经或必然采用 Cu–Cu 混合键合。
2. **CIS、3D NAND、logic/cache 的商业状态不同。** Sony 的堆叠 CIS 与 AMD 3D V-Cache 可作为商业产品路线，YMTC Xtacking/Kioxia CBA 可作为 array–periphery 分离制造/晶圆键合商业架构；但没有逐产品机制原文时，不得把 3D NAND 品牌或 CIS 全产品族统计成 Cu–Cu hybrid-bonded units。
3. **CoWoS、EMIB、I-Cube/H-Cube、Foveros 一般版本、TSV+micro-bump/TCB 都不自动等于 direct hybrid bonding。**
4. **设备收入/订单是设备侧的实际商业事实，不能换算为下游 wafers、die、packages 或 HBM stacks。** 同样，总封测营收、厂房面积、CapEx、总 WPM 和产品/分部收入都不是指定直接键合工艺的有效产能。
5. **中国大陆拥有广泛的相关工艺模块，而端到端、产品级、可审计 Cu–Cu 混合键合规模量产闭环尚未被公开披露充分证明。**
6. **算苗：** 官网能证明公司作出“基于混合键合的 3D 堆叠”技术主张并给出营销规格；媒体可旁证 A4E 流片和“8 层/TSV+bump”的单方发布口径；但 Cu–Cu 精确结构、HBM 与否、存储/晶圆/OSAT/设备材料供应商、客户、有效产能和实际出货都不得填入事实账本。

## 4. 初审必须统一的红线

1. **不得把 XMC/武汉新芯、绍兴新芯及其历史/近名主体混写。** 在没有当前法定主体、原始工艺文件和产品交付证据前，任何“XMC 已具某 Cu–Cu 产能/客户”的句子都不进入总报告。
2. **不得把 2026 年兆易—长鑫 57.11 亿元称作实际采购。** 可写的是：2025 年实际发生 11.82 亿元；2026 年 57.11 亿元为预计关联交易额度。二者均与算苗没有公开供应关系。
3. **不得把 Sony、AMD、YMTC/Kioxia 的不同证据层级合并成一个“已大规模 Cu–Cu hybrid bonding 市场”。** Sony 的直接 Cu 连接需要按技术/产品族和机制原文限定；AMD 是 product + 3D chiplet/SoIC 生态的商业例证；YMTC/Kioxia 是 3D NAND 分离架构/键合例证，Cu–Cu/oxide 机制须逐代确认。
4. **不得把“通过客户验证”“产业化应用”“ready for mass production”“平台可用”“流片”写成实际产出、满产或销售。**
5. **不得把设备、材料、OSAT、foundry 的相关性改写为算苗或任一未具名 AI/HBM 项目的供应商。**
